Capstone Enhancements

For my capstone project, I enhanced the Travlr full-stack web application across three areas: software engineering and design, algorithms and data structures, and databases. Since the same application was used for each enhancement, the original artifact files are provided once and referenced throughout the portfolio.

Original Artifact: Travlr Full-Stack Application

The original artifact is the Travlr full-stack web application. It includes an Angular admin interface, backend API logic, and a database model for storing trip records. This original artifact was used as the starting point for all three enhancements.

  • Original Travlr Artifact Files

Enhancement One: Software Engineering and Design

This enhancement focused on improving the Travlr admin trip management workflow. I improved the edit trip process, updated the form layout, added clearer validation feedback, and changed the edit workflow to use route parameters instead of local storage. These changes improved the usability, maintainability, and structure of the admin side of the application.

  • Original Artifact Files
  • Enhanced Software Design Files
  • Software Engineering and Design Narrative

Enhancement Two: Algorithms and Data Structures

This enhancement focused on improving how trip records are processed and displayed. I added search and sorting functionality so users can search by trip name, resort, or trip code and sort trips by price, name, or date. This enhancement demonstrates the use of arrays, filtering logic, conditional logic, comparison operations, and sorting.

  • Original Artifact Files
  • Enhanced Algorithms and Data Structures Files
  • Algorithms and Data Structures Narrative

Enhancement Three: Databases

This enhancement focused on improving the database layer of the Travlr application. I strengthened the Mongoose schema, improved validation, changed the price field from a string to a number, improved backend error handling, and aligned the frontend model with the backend schema. These changes improved data integrity and made the application more reliable.
